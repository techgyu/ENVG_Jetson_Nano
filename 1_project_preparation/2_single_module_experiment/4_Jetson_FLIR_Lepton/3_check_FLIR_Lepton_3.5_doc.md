## 1. Overview
Principal Uses : Imaging Applications
Sensor Technology : Uncooled Microbolometer
Spectral Band : Long Wave Infrared, 8 um to 14 um
Resolution : 160 x 120 progressive scan
Pixel Size : 12 um
Frame Rate : 8.7 Hz(commercial application exportable)
Sensitvity : < 50 mK(0.050 C)
Non-Uniformity Correction : Intergrated Shutter
Scene Dynamic Range: 
- High Gain Mode: -10 C to 140 C (14 F to 284 F)
- Low Gain Mode: -10 C to 400 C (14 F to 752 F)
Image Optimization : Factory configured and fully automatic
FOV - Horizontal : 57 degrees
FOV - Vertical : 71 degrees
f number : f/1.1
Output Format : User-selectable 14-bit, 8-bit(AGC applied), or 24-bit RGB(AGC and colorization applied)
Solar Protection : Intergrated

## 2. Electrical

Video Data Inteface : Video over SPI
Control Port : CCI(i@C-like), CMOS IO Voltage Levels
Input Supply Voltage : 2.8 V, 1.2V and 2.5V to 3.1V IO
Power Consumption(Typical, room temp): Nominally 150 mW(operating), 650 mW(during shutter event), 5 mW(standby)

## 3. Mechanical

Weight : 0.9 grams

# 한국어 요약
## 1. 개요(Overview)
- **주요 용도:** 영상(이미지) 응용
- **센서 기술:** 비냉각 마이크로볼로미터
- **스펙트럼 대역:** 장파장 적외선, 8μm ~ 14μm
- **해상도:** 160 x 120 프로그레시브 스캔
- **픽셀 크기:** 12μm
- **프레임 속도:** 8.7 Hz (상업용 수출 가능)
- **감도:** < 50 mK (0.050°C)
- **비균일성 보정:** 통합 셔터
- **장면 동적 범위:**
  - 하이 게인 모드: -10°C ~ 140°C (14°F ~ 284°F)
  - 로우 게인 모드: -10°C ~ 400°C (14°F ~ 752°F)
- **이미지 최적화:** 출고 시 공장 설정 및 완전 자동
- **수평 시야각(FOV):** 57도
- **수직 시야각(FOV):** 71도
- **조리개값(f number):** f/1.1
- **출력 포맷:** 사용자가 선택 가능한 14비트, 8비트(AGC 적용), 또는 24비트 RGB(AGC 및 컬러맵 적용)
- **태양광 보호:** 통합

## 2. 전기적 사양(Electrical)
- **입력 클럭:** 25MHz 표준, CMOS IO 전압 레벨
- **비디오 데이터 인터페이스:** Video over SPI
- **제어 포트:** CCI(I²C 유사), CMOS IO 전압 레벨
- **입력 전원:** 2.8V, 1.2V, 2.5V ~ 3.1V IO
- **소비 전력(실온 기준):** 동작 시 약 150mW, 셔터 동작 시 650mW, 대기 시 5mW

  - 소켓 제외: 11.5 x 12.7 x 6.9 mm
