# 2025-09-27 | Laptop Anaconda yolo11n-seg 실시간 객체 외곽선 탐지 설계

---

## 1. 기본 설계 (구체화)

1. **지정된 화면 영역 캡처**
	- 사용자가 지정한 윈도우 또는 화면 영역을 주기적으로 캡처 (예: pygetwindow, mss, pyautogui 등 활용)
	- 캡처 주기(프레임레이트)는 설정값으로 조절 가능 (예: 1/24초마다 1회)

2. **객체 인식 및 외곽선 탐지**
	- 캡처된 이미지를 YOLO11n-seg 모델에 입력하여 객체 검출 및 마스크(외곽선) 추출
	- CPU 환경에서도 동작하도록 모델 경량화 및 추론 최적화
	- `6_test_yolo11n_seg_docker.py` 참고

3. **외곽선 좌표 반환**
	- 검출된 객체별로 외곽선(폴리곤, 컨투어 등) 좌표를 리스트로 반환
	- 필요시 객체 클래스, 신뢰도 등 부가 정보도 함께 반환

4. **화면 위에 외곽선 그려냄**
	- 원본 캡처 이미지 위에 외곽선을 시각적으로 오버레이
	- OpenCV, PIL 등으로 실시간 렌더링
	- 현재 보고 있는 윈도우 화면에 반영(overlay) 가능

## 2. 추가 고려사항

- **CPU 환경에서 실시간 처리 가능할 것**
- **캡처 주기 조절 가능할 것** (1/24초에 1회 등)
- **윈도우/캡처 영역 동적 조절** (캡처되는 영역이 동적으로 변환)
- **성능 최적화**: 프레임 드롭 최소화, 멀티스레딩/비동기 처리, 불필요한 연산 최소화
- **유저 인터페이스**: 간단한 GUI(예: PyQt, tkinter)로 영역 지정, 캡처 주기 조절, 결과 확인 등 지원
- **로깅 및 예외 처리**: 오류 발생 시 로그 기록, 예외 상황(캡처 실패, 모델 추론 실패 등) 처리
